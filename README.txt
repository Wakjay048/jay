AUGUSTAV FAHRUL ALZAIYA — PIXEL NIGHT PORTFOLIO

JALANKAN WEBSITE
1. Ekstrak ZIP.
2. Buka folder di Visual Studio Code.
3. Jalankan index.html menggunakan Live Server (disarankan), atau buka langsung di browser.
4. Google Fonts memerlukan koneksi internet; website tetap memiliki font fallback jika offline.

FOTO PROFIL
Tambahkan foto bernama assets/profile.png. Jika memakai JPG, ubah atribut src pada gambar profil di index.html.

SERTIFIKAT PDF
Letakkan file PDF di assets/sertifikat/ dengan nama persis:
- sertifikat-1.pdf
- sertifikat-2.pdf
- sertifikat-3.pdf
- sertifikat-4.pdf
- sertifikat-5.pdf

Tiap kartu menyediakan tombol Lihat PDF dan Download. Preview menggunakan PDF viewer browser.
Pada sebagian browser mobile, PDF mungkin terbuka di tab baru atau aplikasi PDF; tombol Buka tab baru dan Download disediakan sebagai alternatif.

EDIT WEBSITE
- index.html: isi dan struktur.
- css/style.css: desain, warna, layout responsive.
- js/script.js: menu mobile, scroll reveal, navigasi, dan PDF viewer.

Website bersifat statis dan tidak membutuhkan database/backend.
